# StableWatts

<p align="center"><img src="./docs/logo.png" style="height: 211px; width: 499px" /></p>

StableWatts is a formula for a self-adaptive software-defined power meter based on the [`PowerAPI framework`](https://github.com/powerapi-ng/powerapi). This formula is designed to provide stable and accurate power metrics that facilitate the implementation of power control mechanisms in multi-container environments. StableWatts is built on top of the well-known [`SmartWatts`](https://github.com/powerapi-ng/smartwatts-formula.git) power meter. For more information, please refer to the original SmartWatts paper: [`SmartWatts: Self-Calibrating Software-Defined Power Meter for Containers`](https://ieeexplore.ieee.org/document/9139675).
